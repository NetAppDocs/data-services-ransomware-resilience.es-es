Al activar la detección de actividad de usuario en Ransomware Resilience, esta función utiliza las credenciales guardadas actualmente en Console para gestionar los recopiladores de datos. Si anteriormente habías habilitado la detección de actividad de usuario a través de Data Infrastructure Insights (DII) Workload Security, las credenciales de Console sustituirán a las que utilizabas anteriormente en DII para gestionar los recopiladores de datos.
