=== Extensiones de archivo bloqueadas administradas

Ransomware Resilience ahora te permite personalizar la lista de extensiones de archivo permitidas o bloqueadas en una carga de trabajo cuando has habilitado la opción de protección *Bloquear extensiones de archivo sospechosas*. Con esta mejora, puedes configurar la carga de trabajo para que solo permita tipos de archivo específicos en la VM de almacenamiento (SVM) o para bloquear extensiones de archivo específicas. Esta mejora admite un control más detallado sobre la opción de extensiones de archivo y también te permite crear listas diferentes para distintas SVM.

Para obtener más información, consulta link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-file-extensions.html["Gestionar las extensiones de archivo bloqueadas en Ransomware Resilience"].
